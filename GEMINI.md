# Antigravity Instructions

## Session Synchronization Protocol
- Before starting any task:
  1. Inspect `SESSION_LOG.md` to see the current project state and recent handoffs.
  2. Run `git log -n 3` to review recent commit history.
- After completing a task or milestone:
  1. Update `SESSION_LOG.md` with:
     - What was implemented or modified.
     - Any new dependencies, scripts, or architectural decisions.
     - Clear next steps for the next session.
  2. Commit your changes with a descriptive Git message.

## Git and GitHub
- Do not add your name or any AI attribution as a collaborator or co-author when committing or pushing to GitHub: no `Co-Authored-By` trailer, no "Generated with..." line, and no mention of AI agents or models in commit messages, PR titles, or PR descriptions.
- Commit messages should read as written by the user alone.
