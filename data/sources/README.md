# Source documents

Put one .md or .txt file per source here (papers, cultural-office pages, museum pages, video transcripts).

- Name the file after the source, e.g. `ntb-culture-office-gendang-beleq.md`. The name is shown as the citation.
- Put the full URL or reference on the first line of the file.
- Paste the text only; do not copy long passages you don't have rights to. Summarise and cite.
- Aim for 15-30 sources. Then run `python ingest.py`.
